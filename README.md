# PNIPU_Planner

Университетский помощник — приложение для студентов ПНИПУ, помогающее организовать учебный процесс.

## 📋 Возможности

- **Главная страница** — быстрый доступ к задачам и расписанию
- **Планировщик** — управление расписанием занятий с поддержкой чётных/нечётных недель
- **Будильник** — напоминания о начале пар с настраиваемым временем
- **Настройки** — выбор темы оформления (светлая/тёмная/системная), имя пользователя

## 🛠 Технологии

- **Python 3.x**
- **Flet** — фреймворк для создания кроссплатформенных UI
- **Threading** — фоновые задачи (обновление времени, проверка будильников)

## 🚀 Установка и запуск

1. Установите зависимости:
```bash
pip install flet
```

2. Запустите приложение:
```bash
python app/main.py
```

## ⚙️ Конфигурация

Приложение хранит настройки в менеджере конфигурации:
- Имя пользователя
- Тема оформления (light/dark/system)

Расписание занятий загружается из `app/data/schedule.json` и автоматически применяется на указанный семестр.
